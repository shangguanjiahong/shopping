# 地区代理管理菜单配置说明

## 概述

本文档说明如何为CoreShop系统添加地区代理管理功能的菜单配置，使地区代理管理页面能够在管理后台的侧边栏中正确显示。

## 功能说明

地区代理管理系统包含以下主要功能：

### 1. 地区代理管理
- 地区代理列表查看
- 添加新的地区代理
- 编辑地区代理信息
- 删除地区代理
- 启用/禁用地区代理
- 设置代理佣金比例
- 查看代理详情和统计

### 2. 地区代理订单记录
- 查看地区代理订单列表
- 订单详情查看
- 订单结算管理
- 批量结算操作
- 统计数据查看

## 菜单结构

配置完成后，菜单结构如下：

```
代理设置 (ID: 630)
├── 代理设置 (ID: 635)
├── 代理商品池 (ID: 660)
├── 代理等级 (ID: 631)
├── 代理商列表 (ID: 632)
├── 代理商订单 (ID: 633)
├── 地区代理管理 (ID: 1200) ← 新增
└── 地区代理订单记录 (ID: 1201) ← 新增
```

## 安装步骤

### 1. 选择对应的数据库脚本

根据您使用的数据库类型，选择对应的SQL脚本：

- **MySQL数据库**：使用 `数据库/MySql/地区代理菜单配置.sql`
- **SqlServer数据库**：使用 `数据库/SqlServer/地区代理菜单配置.sql`

### 2. 执行SQL脚本

#### MySQL数据库
```sql
-- 连接到您的CoreShop数据库
USE your_coreshop_database;

-- 执行菜单配置脚本
source 数据库/MySql/地区代理菜单配置.sql;
```

#### SqlServer数据库
```sql
-- 连接到您的CoreShop数据库
USE [your_coreshop_database]
GO

-- 执行菜单配置脚本（复制粘贴SQL内容并执行）
```

### 3. 验证安装

执行以下SQL查询验证菜单是否正确添加：

```sql
-- 查看新增的主菜单项
SELECT * FROM SysMenu WHERE id IN (1200, 1201);

-- 查看所有地区代理相关的菜单项
SELECT * FROM SysMenu WHERE id BETWEEN 1200 AND 1225 ORDER BY id;
```

### 4. 重启应用

执行SQL脚本后，需要重启CoreShop应用程序以使菜单配置生效。

### 5. 权限配置

登录管理后台，进入 **后台管理 > 角色管理**，为相应的角色分配地区代理管理的权限：

1. 选择要配置的角色
2. 在权限设置中找到 "代理设置" 分组
3. 勾选以下权限：
   - 地区代理管理
   - 地区代理订单记录
   - 相关的API权限

## 菜单项详细说明

### 主菜单项

| ID | 菜单名称 | 路径 | 权限标识 | 说明 |
|----|----------|------|----------|------|
| 1200 | 地区代理管理 | agent/agentArea/index | agent:agentArea:index | 地区代理管理主页面 |
| 1201 | 地区代理订单记录 | agent/agentAreaOrder/index | agent:agentAreaOrder:index | 地区代理订单记录主页面 |

### API权限菜单项

#### 地区代理管理API (1202-1216)
- 获取列表、首页数据、创建数据、编辑数据
- 删除操作、预览数据、设置启用状态
- 获取代理商列表、地区树、省市县列表

#### 地区代理订单API (1217-1225)
- 获取列表、首页数据、预览数据、编辑提交
- 获取统计数据、结算操作、批量结算
- 设置结算状态

## 注意事项

1. **ID冲突检查**：执行脚本前，请确认ID 1200-1225 在您的SysMenu表中未被使用
2. **父级菜单**：脚本假设ID 630（代理设置）菜单项已存在
3. **权限分配**：执行脚本后需要手动为角色分配相应权限
4. **缓存清理**：如果使用了菜单缓存，可能需要清理缓存

## 故障排除

### 菜单不显示
1. 检查SQL脚本是否执行成功
2. 确认应用程序已重启
3. 检查当前用户角色是否有相应权限
4. 清理浏览器缓存

### 权限错误
1. 检查角色权限配置
2. 确认API权限菜单项已正确添加
3. 检查权限标识是否正确

### ID冲突
如果遇到ID冲突，请修改脚本中的ID值，确保使用未被占用的ID。

## 卸载

如需移除地区代理菜单配置，执行以下SQL：

```sql
-- 删除地区代理相关菜单项
DELETE FROM SysMenu WHERE id BETWEEN 1200 AND 1225;

-- 删除相关角色权限（如果需要）
DELETE FROM SysRoleMenu WHERE menuId BETWEEN 1200 AND 1225;
```

## 技术支持

如果在配置过程中遇到问题，请检查：
1. 数据库连接是否正常
2. SQL脚本语法是否正确
3. 应用程序日志中是否有错误信息
4. 前端页面文件是否存在
